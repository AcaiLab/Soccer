\section*{Project Overview}
Our project investigates how vision-language models can identify important events in soccer match
videos and generate natural-language commentary describing those events. Our main goal is to
determine how accurately soccer events can be identified from video, and how those events can be
used to generate accurate commentary for different audiences, including casual viewers, expert fans,
and people with low vision. The project builds on the SoccerReplay-1988 dataset~[5] and existing
baseline methods for soccer event classification.

\section*{Current Progress}

\subsection*{1. Baseline results on real data}
\textbf{Data.} 65 English Premier League 2021--22 matches; 4,337 events of 22 event types (the
excluded labels are listed in Table~\ref{tab:labels}). Each event is described by one frame per second
from 30\,s before to 30\,s after its timestamp, each frame encoded with frozen DINOv2-base~[3].

\textbf{Protocol.} 5-fold cross-validation by whole match: each fold tests 13 matches, tunes on 7
other matches, and trains on the remaining 45, so every match is a test match exactly once and no
match is ever on both sides. Every choice (pooling, classifier, stopping epoch) is made on the fold's
validation matches only; test matches are scored once. Two seeds per fold.

\begin{itemize}[noitemsep]
  \item \textbf{Pooled frozen features}: each event's frame vectors pooled into one (mean, max, first or
        last frame), fed to logistic regression, a linear SVM or a small MLP; the best pairing on validation
        is tested.
  \item \textbf{Sequence model}: four temporal models (mean-pool MLP, BiLSTM, temporal CNN, Transformer)
        compared on validation; the BiLSTM won in every fold.
  \item \textbf{Visual + annotation}: pooled visual features plus features from earlier annotated events
        (previous three event types, counts over the last five minutes).
  \item \textbf{Official split} (50 train, 7 validation, 8 test matches, 5 seeds), for comparison: accuracy
        0.390 (pooled), 0.421 (visual + annotation) and 0.491 (sequence) against a baseline of 0.166.
\end{itemize}

\subsection*{3. Clustering: embeddings follow the match, not the event}
Without labels, K-Means groups of raw DINOv2 event vectors follow \emph{which match} an event came from
far more than \emph{what happened}. On the 15 held-out matches of the official split, cluster agreement
(ARI) with match identity is 0.354, against 0.035 with event type. A contrastive projection head trained
with a triplet loss~[6] on training matches only (positive: same event type from another match; negative:
another event type from the same match) removes the match signal (0.029) and raises event agreement to
0.106. In cross-validation, event agreement rises from $0.031 \pm 0.002$ to $0.094 \pm 0.003$, up in all 5
folds. The gain is consistent but small, and the head mostly memorises its training matches (event ARI
0.73 there). We also produced t-SNE maps~[8] of all 4,337 events, coloured by event type and by match:
the event types are mixed throughout, while each match forms its own island.

\section*{Challenges and Issues}
\textbf{Hidden data problems.} Validating the migrated data showed that the older extraction had cut
47\% of events in one audited match from the wrong half's video, and that some recordings state a wrong
frame rate, so frames drifted from the video clock. Both are fixed; after re-extracting, the results
moved by less than the variation between seeds.

\textbf{Part of each frame is never seen.} DINOv2's standard preprocessing resizes each frame and crops
its centre to 224\,$\times$\,224 pixels, so for broadcast 16:9 video it sees about 43\% of the image. We have
not yet tested whether the cut-off sides of the pitch matter.

\textbf{Class imbalance.} Corners are 16.4\% of events, while penalties (12), throw-ins (7) and a second
yellow card (1) are barely represented. These types score zero and pull macro-F1 down.

\section*{Next Steps}
\begin{enumerate}[noitemsep]
  \item Switch model selection to validation macro-F1 and rerun the cross-validation.
  \item Scale up in stages within the Premier League: 552 matches across seven seasons are available. This
        also makes a whole-season hold-out possible.
  \item Sweep the contrastive embedding size (64, 128, 256, 512) and add class-balanced anchor sampling.
  \item Audit a random sample of annotations by eye to estimate how often labels are wrong.
\end{enumerate}
